# ひなポコ HINAPOKO

4〜8歳向けのオリジナル3マッチパズル。現在は Phase 1 のステージ01を実装しています。ゲームルールは Phaser の描画から独立した TypeScript モジュールにあります。

## 開発

必要環境: Node.js 20 以降、npm 10 以降。

```sh
npm ci
npm run dev
```

ブラウザーで表示された URL を開きます。固定シードの盤面は `?seed=1` のように指定できます。

```sh
npm test
npm run build
npm run preview
```

## 操作

- 隣り合う動物をスワイプするか、2匹を順番にタップして交換します。
- 3匹以上そろうと消え、上の動物が落ちて新しい動物が補充されます。
- 石板の上で動物が消えると石板を壊します。ステージ01は12手以内に3枚壊すとクリアです。
- 無効な交換は手数を使いません。最初の盤面では光る2匹を交換すると必ずクリアできます。
- 「もういちど」で無料でやり直せます。クリア記録は LocalStorage に保存します。
