# ひなポコ HINAPOKO

4〜8歳向けのオリジナル3マッチパズルです。TypeScript + Phaser 3 + Vite で作り、ゲームルールと描画処理を分けています。

## 開発

必要環境: Node.js 20 以降、npm 10 以降。

```sh
npm ci
npm run dev
```

ブラウザーで表示された URL を開きます。固定シードの盤面は `?seed=1` のように指定できます。

```sh
npm test
npm run build
npm run preview
```

## 操作

- 隣り合う動物をスワイプするか、2匹を順番にタップして交換します。
- 3匹以上そろうと消え、上の動物が落ちて新しい動物が補充されます。
- 盤面の上に出る「けした どうぶつ」の数を目標まで増やすとクリアです。動物の種類は問いません。
- 無効な交換は手数を使いません。最初の盤面では光る2匹を交換すると必ずクリアできます。
- 「もういちど」で無料でやり直せます。クリア後は「つぎへ」で進み、進行状況を LocalStorage に保存します。
- 5秒間操作がないと交換のヒントが動きます。スワイプと2タップに対応します。
- 4個直線で矢印爆弾、5個直線でレインボー爆弾、T/L字でダブル爆弾を作ります。交換先のマスを生成場所にし、交換先がマッチに含まれない時は交換元を使います。落下連鎖で生成する場合は、マッチ位置の先頭（上から左）のマスに作ります。
- 矢印は行または列、ダブルは中心から2マスの範囲、レインボーは隣の動物と同じ種類を消します。爆弾同士は両方の効果を続けて起動し、レインボー同士は盤面全体を消す独自仕様です。

## 現在の範囲

実装済み: 5×5〜7×7の10ステージ、動物5種の独自ベクター仮アート、縦横マッチ、無効手の巻き戻し、手数、動物消去数の目標、穴、重力、補充、連鎖、3種の爆弾、手詰まり時のシャッフル、操作ヒント、クリア・失敗表示、LocalStorage の進行記録、効果音の ON/OFF、PWA マニフェストとオフラインキャッシュ、GitHub Pages 用 GitHub Actions。

障害物セルは現在「穴」のみです。実機 iPad の Safari と Windows のブラウザーでは未検証です。
